# Trabajo Práctico Integrador - IAEW 2026

Carpeta publicable para estudiantes con la consigna del TPI, dominios sugeridos y página de acceso.

## Archivos

- [enunciado.md](enunciado.md): consigna formal, fechas, entregables y criterios de evaluación.
- [dominios.md](dominios.md): dominios ordenados con alcance esperado, entidades, flujo principal, integración, seguridad y observabilidad.
- [index.html](index.html): página navegable para consultar el TPI desde el navegador.

## Seguridad requerida

El proyecto debe usar OAuth 2.0/JWT con Auth0 o proveedor equivalente, validar scopes en endpoints protegidos e incluir un ejemplo mínimo de `api_key`.
